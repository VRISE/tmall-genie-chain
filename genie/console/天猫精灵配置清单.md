# 天猫精灵后台配置清单（板子 192.168.5.142:8090）

平台：iap.aligenie.com → 创建**自定义技能**（语音技能，不是小程序）。

## 1. 基本信息
- 名称：家里随便起，例：`小盒管家`
- 上架方式：**私有应用**（只给自己设备用，不用审核，走真机测试）
- 调用词：必须设，且要独一无二（发音撞车也算重复）。例：`小盒管家`
  - 只有带调用词才能进默认意图，NLU 兜底那条路就靠它

## 2. 实体（3 个自定义 + 引用公共实体）
| 实体名 | 标识 | 词表来源 |
|---|---|---|
| 年级 | grade | `实体_年级.csv` |
| 学科 | subject | `实体_学科.csv` |
| 话题 | topic | `实体_话题.csv`（不够就点「算法推荐」，支持 学科知识/节目/电影/歌曲/书/演员…） |

- 批量：实体页 →「批量上传」下模板填好再传；一次手工输入最多 20 个
- 词条别带英文字母（ASR 会把数字念成中文）

## 3. 意图 + 参数 + 语料
### 意图一：看视频（方案A，平台帮你解析）
参数：`grade`→年级实体、`subject`→学科实体、`topic`→话题实体
语料（模板式，控制台「批量导入」用 `语料.csv`）：
```
给我看一下@{grade}的@{subject}视频
给我看一下@{topic}视频
```
- 只填模板，词条留给实体；穷举版 `语料.自动.csv` 有 88458 句，一般不用传
- 「用户可能回复」这一栏只能填模板式语料

### 默认意图（方案B，原话直接给我们）
- 不配语料：文档写明「默认意图可以不依赖语料进入」，只说调用词就进来
- 未命中的句子会「跳出技能」，所以兜底只有默认意图这一条路

## 4. 服务部署（Webhook）
| 意图 | 回复逻辑里填的地址 |
|---|---|
| 看视频 | `https://<公网地址>/aligenie/corpus` |
| 默认意图 | `https://<公网地址>/aligenie/nlu` |
| 懒得区分 | 两处都填 `https://<公网地址>/aligenie/webhook`（按 intentName 自动分） |

要求：http(s) POST + `Content-Type: application/json`；响应必须是 JSON，
我们这边回 `application/json`，`reply` 一定会被 TTS 念出来。

**校验文件**：平台给的文件名+内容，原样存成板子上
`/etc/genie/aligenie/<它要的文件名>.txt` 即可，我们用
`GET /aligenie/<同名>` 原样吐出。

公网地址：板子上 `cpolar-genie.service` 已配好（只挂 8090，不碰 22），
缺 authtoken。在你自己终端跑一次就行（别把 token 发聊天里）：
```
echo '你的token' | ssh root@192.168.5.142 'install -m 600 /dev/null /etc/genie/cpolar.token; cat > /etc/genie/cpolar.token'
ssh root@192.168.5.142 'systemctl enable --now cpolar-genie; sleep 5; curl -s localhost:4040/api/tunnels'
```
第二条会打印 `https://xxxx.cpolar.top`，那个就是公网地址（free 套餐每次重启会换域名）。

## 5. 测试
- 在线测试：不带真机，先用 `curl` 那两条样例打一遍（`请求样例.方案A.json`、`请求样例.方案B.json`）
- 真机测试：绑定你这台音箱后，说「天猫精灵，小盒管家」→ 进默认意图 → 再说「给我看一下初一的数学视频」
- 开麦续话要在「授权配置 → 申请技能权限包」里勾「允许通过 Webhook 触发音箱开麦行为」

## 6. 已实测的上限
- 文档通篇没写语料条数/意图数/实体词条数的上限，也没写 webhook 超时秒数
- 我们按 2.5 秒设计：这一跳绝不等大模型，慢答案由手机说（已跑通）
