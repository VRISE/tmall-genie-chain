## 控制台接口（在自己登录的浏览器里，同源才带 cookie）

```
GET  /api/newskill/<appId>                                  技能属性（isPublic / subIaType）
GET  /api/skill/<sid>/intents?pageNum=1&pageSize=200        意图列表（注意是 pageNum，不是 pageNo）
GET  /api/skill/<sid>/intent/<iid>                          意图详情：userSays / parameters / webhook
GET  /api/skills/<sid>/entities?pageNo=1&pageSize=50        实体列表
GET  /api/skills/<sid>/entities/<eid>/entries?pageNo=1&pageSize=3000   实体值（字段是 normValue）
POST /api/skills/<sid>/entities/<eid>/entries?ctoken=<cookie里的ctoken>
     header x-csrf-token: <同上>，body {"normValue":"周杰伦","synonyms":[]}
POST /api/corpus/skills/<sid>/update/model                  触发「语音交互模型训练」
PUT  /api/hybird/updateV2                                   保存基本信息（改技能名/调用词就走它）
GET  /api/skill/invocation/update/exist?skillId=<sid>&str=<候选词>   调用词有没有被占用
```

改调用词的界面路径（SPA 会粘住上一个技能，别直接开 deep link）：**技能列表 `/home` → 点那张卡片 → 编辑信息 → 「技能调用词」输入框 → 保存**。
`evaluate_script` 在这个控制台（连纯 JSON 页面都一样）永远返回 `{}`，只有 `fill`/`click`/`wait_for`/截图可用 —— 别指望在页面里跑 JS 读配置。

**但灌值/加语料不需要 JS，纯点 UI 就够**（2026-09-29 实测：46 条实体值 + 12 条例句，零失败）：

```
fill(输入框的 uid, "要加的话")   →   press_key("Return")
```

回车后焦点还留在同一个框里，后面几条只 `fill`+`Return` 就行；读页面和拿 uid 一律用 `wait_for(["关键字"])`，**uid 几秒就过期，拿到立刻用**。
两个框的规矩不一样：**实体值框按空格分条**（一次最多 20 条），**语料框不按空格分**（「帮助 你是谁」会被当成一整条），而且语料框**拒收 `[` `]`** —— 所以裸 `[话题]` 模板打不进去，那个「例句/模板」下拉和「批量导入」（原生文件 picker）都不在无障碍树里，够不着。
加完点**提交**（`PUT /api/skills/<sid>/intents/<iid>`，成功后页面退回意图列表），再点**编辑**回到意图编辑页，**「语音交互模型训练」按钮只在编辑页底部**，点它 → `POST /api/corpus/skills/<sid>/update/model`。
有没有真发出去，看 `list_network_requests`（**不能带 `resourceTypes` 参数**，带了会报错）。
语料两种写法：**例句**（`@{话题}` 是控制台标出来的样子）和**模板**（自己写 `[话题]`）。**模板那条路我走不通**（切换下拉不在无障碍树里，且语料框拒收 `[` `]`），所以新加的都是整句例句。当前意图 `play_video`（190791）共 **48 条**，其中一批是专门为了「不带槽位也能路由」写进去的整句：`能放动画片吗`、`动画片`、`你是谁`、`帮助`、`你有什么功能`、`你会做什么`、`你能干什么`、`你可以帮我干什么`、`讲故事`、`听故事`、`听歌`、`放首歌`。
**记住：实体值只透过已有句式命中**，语料里没有裸 `[话题]`，所以灌再多话题也必须配上对应说法；反过来，「能不能/帮我」这类整句必须一条一条写进语料。

## 实测结论（别再重新发现一遍）

1. **平台等这一跳只等 1.5～2 秒**（2026-09-29 注入延迟二分出来的：1s 播、1.5s 播、2s 不播、3s 不播）。所以豆包（5～20 秒）永远不可能让音箱同步念出来。
2. **只有灌进实体的说法能被路由**。不在实体里的句子，平台 NLU 直接丢（`意图/null`），我们服务端一条 POST 都收不到 —— 猪八戒和两只小狗（一个是公有自定义、一个是私有个人技能）**行为一样**，没发现私有更宽松。
3. **「说调用词 + 任意一句话」做不到**，这个技能天生是「几千条枚举指令的遥控器」。别再生成"规则引擎/正则兜底"的主意。**但有一条官方留的口子能把"任意话"变成"当场报菜名"，见下面第 12 条的 SELECT。**
4. **控制台的「在线测试」页不能用**：技能没发布（`status:OFFLINE`）时，连喂过值的句子也回 `意图/null`。要验路由只能对着方糖说话，然后看盒子 `curl -s -m3 localhost:8092/log`。
5. **豆包爱写 markdown、爱加 emoji、爱列 1.2.3.、爱写长，还爱顺手甩一条抖音链接**，音箱会把「井号」「对勾」和「https 点点」念出来，两行粘成一句还会把数字念错。`targets._plain()` 负责收成能念的话：剥 emoji 和 markdown、**行与行之间补「。」**、剥行首编号、**剔掉 `http(s)://` 网址**、折叠「。。」、超 80 字就退回上一个完整句子、`《` 没配上 `》` 就退到 `《` 之前。剔完网址什么都不剩的，`remember()` 直接不入库（返回空串），免得音箱念一串乱码；`/teach` 的日志因此打的是**真正会念出来的那句**，没存会写「豆包只给了链接，没存」。同理「角色介绍：」这类小标题下面的正文被剥光后，剩下光秃秃的冒号也会被删（念着像卡壳）。库里**旧的条目是被老版本粘成一整行的，读的时候救不回来** —— 嫌难听就 `pop` 掉那个 key、`systemctl restart genied42`、再走 `/teach` 重灌。
6. **`/teach` 口**（`POST localhost:8092/teach`，json 数组或一行一条）只灌答案库不出声，批量备料用它；真链路测试才走 `/`。**喂裸名词（葫芦娃、猪猪侠、花园宝宝）豆包十次有十次只甩一条抖音链接、不给话**，得用「讲讲X」这种完整句式问，才换回一段能念的介绍。
   - **`/test` 的句子必须用 `--data` 传**：`curl -XPOST host/test "句子"` 会把句子当成第二个 URL，body 成 0B，落到默认语句「给我看一下初一的数学视频」= 播放类，**电视直接开始放视频**。写 `--data "句子"` 才对；救火用 `curl http://127.0.0.1:7799/stop`，`pgrep -a mpv` 空了才算停。
   - 挑这一批灌哪 20 句：`genie/console/挑待灌.py`（照抄 `_LEAD/_TAIL/子串兜底` 做贪心，一条答案顶几句是算出来的）。2026-09-29 08:0x 库 303 条、实体 1435 句里 139 句能秒答，还剩 1296 句≈65 批。
7. **答案库按「主题词」认，不按整句认**（`targets._core()` 把「讲讲/介绍一下/…的故事/…的历史」这类前后缀剥掉再比）。一条答案顶九种问法，不然 357 个话题 × 35 种句式要灌一万多条。已实测 8/9 种问法命中，控制组「讲讲量子纠缠」正确落空。**存进去的 key 是原句**（只有标点空格被去掉），所以要查某条灌没灌上，比 `core(key)`，别拿裸话题名去 grep。
   - **2026-09-29 早上又宽了一圈**（`targets.py` md5 `ccba66c5…`）：`_LEAD` 加 `能不能|能|可以`，`_TAIL` 加 `能放|能看|可以看|可以放|想看|要看|吗`。现在 `能不能放足球吗 / 可以放足球吗 / 我想看足球 / 放足球 / 给我放足球 / 足球能放吗 / 帮我放足球 / 讲讲足球 / 足球是什么 / 足球的故事` **十种问法全折成同一个 core**，一条答案顶十句。老句子无回归、库无新碰撞。**推这次只动了 `genielib/targets.py`**（`genied.py`、`plan.py` 当时正被并行会话改，md5 不一致，没碰）。
   - **只有 `action=="ask"` 才查答案库**，播放类句子走 `dispatch`→电视，所以给「能不能放X」灌一条文字答案不会把播放腿搞坏。
8. **豆包给的抖音链接是 `v.douyin.com/abcd` 短链**，`7799/tv` 只认 `/share/video/<19位>`。`targets._short_video_id()` 吃 302 的 Location 把视频号解出来；它常给一条已失效的链（302 回首页），所以换句话再要一次，最多两次。另外 MiGPT 那轮的 `/v1/cards` 里也带视频，一并捡。
9. **`/tmp/qoder-out.txt` 会被并行会话覆盖**（`box-run.sh` 的远端 stdout 落这个固定路径）。要读回来的东西先在远端写唯一文件名 `> /tmp/xxx_$$.log`，再用 `box-run.sh get` 拿。
10. **公网入口要从盒子上验，别从 Mac 验**：Mac 上 `curl https://<域名>.r6.cpolar.top/health` 会返回空 body（Clash/本地网络在拦），看着像服务挂了。判穿透只认盒子侧 `curl -s localhost:8092/health` 和 `~/opt/genie/domain.sh` 现抓的域名。
11. **整句语料命中时平台不给槽位**，`slotEntities` 是空的 → `plan.py` 用 `_tidy()` 从原话里抠出「要放的东西」（剥掉 `吗呢啊吧` + `能不能/可以/帮我/给我/我想` + 开头的 `放/看`）。没这一层，音箱会念「这就放天天同学，动画片」。
12. **NLU 到底能不能"不提前导入"—— 2026-09-29 早上把官方文档读了一遍（`cn4ot8` 语音交互模型概述、`amm8fg` 配置语料、`qyq166` 创建实体、`sgmvp9` 添加参数、`ehac4c`/`megzio` 响应协议、`snoupa`/`omuzxq` 所见即可说），并对着方糖做了对照实验。结论：他怀疑得对，第一句话确实是模板+词典，但有一条官方留的后门能用。**
