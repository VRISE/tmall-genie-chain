# 01 可行性调研：天猫精灵开放平台到底给了我什么口子

> 这份只回答一个问题：**这事能不能做、平台给了什么口子、哪里是死墙。**
> 素材 = 2026-09-27 ~ 10-01 全程流水账 + 线上代码（`genie/genied.py`、`genie/genielib/`）。
> 口径：每条断言后面标日期和「怎么证的」；**只读过文档没真机打过的，我一律写「没测过」**，你别当事实用。
> 文中公网域名一律写成 `<CPOLAR_域名>`：free 套餐的随机域名本身会过期甚至被回收给陌生人，抄进文档只会害人去打别人的服务（见第 6 节）。

## 1. 先说清这套东西在干什么

一句话：**把一台天猫精灵方糖当「白名单开关 + 传声筒」用 —— 它只负责听一句清单里的话、负责开口念我们的回答；判断、白名单、大模型全在我自己局域网的盒子里。**

```
你说话 → 方糖麦克风 → 阿里 NLU（唯一绕不开的一关）
      → POST https://<CPOLAR_域名>.r6.cpolar.top/  → 盒子 :8092 genied
      → 判意图/查答案库/（要放片就投电视、要新答案就后台问豆包）
      → 回一段 JSON 里的 reply 文本 → 方糖自己把它念出来
```

三处落地都验证过（2026-09-30 真机）：音箱念的话 = 我们 `reply` 字段里的字符串；出屏走局域网的 `192.168.5.42` 盒子 HDMI（`migpt` 的 `127.0.0.1:7799/tv`）；慢答案（豆包要 5~20 秒）不进那一跳，后台算好再从电视出声。

**为什么值得这么绕**：官方那条「让音箱自己播我们的内容」的路根本不存在 —— `actions` 只认素材库音频 ID 和 `playTts`，给不了外链 URL（2026-09-27 读文档，`actions` 这条**没实测过**）。所以架构只能是"音箱当耳朵和嘴"。

## 2. 平台开放的能力面（我实际用到的那几项）

### 2.1 动态意图 + webhook：唯一的入口

控制台 = `https://iap.aligenie.com/`（`open.aligenie.com` 301 过去）。建「语音技能」→ 定义意图 → 把意图**设为动态**，之后这句话命中就该意图时，平台以 `application/json` POST 我的公网 URL。

- 「动态」这个开关决定平台调不调我：**非动态时平台自己回一句固定文案，服务端一条请求都收不到**。这条是 2026-09-28 凌晨在 113665 上撞出来的（当时 `play_video` 的动态一直是关的，我怀疑了半小时语料和穿透）。接口 = `POST /api/skill/<sid>/intent/<iid>/toggleDynamic`。
- **排查顺序**：先确认「动态」列 ✓ → 再确认「默认意图」还是「是」 → 再看训练 → **最后才怀疑自己代码**（2026-09-28 一整晚的顺序反了，白改了代码）。

### 2.2 语料 + 实体：这才是那堵「白名单」墙

- 语料两种写法：**例句（`type=SAMPLE`，整句字面匹配）**和 **模板（`type=TEMPLATE`，`@{参数名}` 占位，必须先建参数）**。下拉默认「例句」，例句模式下输入含 `@{}` 的串会被**静默拒绝**（计数不动、无报错，2026-09-28 实测）。
- 实体值三种来源（官方《创建实体》`qyq166`，2026-09-29 读到原文，界面复核）：
  1. **手填**：输入框一次最多 20 个、空格分隔、回车才落；
  2. **「通过 API 动态获取实体值」—— 官方原话「该方式已暂停接入」**，界面上那个单选点不动不是我没找到用法（2026-09-29）。**这条把我原本最想要的「词典放自己服务器」直接关了**；
  3. **算法推荐**：只对**实体名字在白名单里**的实体生效（旅游景点/学科知识/节目/电影/歌曲/歌手/人物/朝代/书/动物…）。我们那个叫「问题」、灌整句的实体点它 =「没有数据」（2026-09-28 实测弹这个）。**「建一个真叫『歌手』的实体能吐几百个值」—— 这条我到最后也没测过。**
- 公共实体 25 条（`sys.time/location/age/color/ordinal/anyNumber/date…`，`GET /api/skill/public/entities` 读到的），平台自带词库。天气能"查任意城市"靠的是它，**不是**平台能吃任意文本。
- 硬顶：实体值 **10000 条**。2026-09-30 02:3x 灌到 101879 那个实体顶死在 10000，之后只能换词不能加词。
- 语料/词条总数：官方 112 页文档**一个数字都没写**（2026-09-27 通读）。
- 批量灌不需要 JS：`fill(uid, 值) → press_key("Return")` 就能加，实测 46 条实体值 + 12 条例句零失败（2026-09-29）。**8158 条整句**走的是"HTTPS 页面自己 fetch 本机 127.0.0.1:8099 的小服务 + 5 路并发 POST"，142 秒 0 失败（2026-09-29 16:2x~16:4x）。

### 2.3 在线测试 vs 真机测试：两条都不完全可信

- **在线测试**（`/api/tools/test`，页面用 `fill`+`click` 就能驱动）：走的是阿里的真 NLU，但**它只测"我这个技能"，绕不过官方技能抢答那一层**（2026-09-30 07:0x 实证：网页 SUCCESS 的句子，方糖上当场被酷狗音乐接走）。早期我记录过「技能没发布（`status:OFFLINE`）时在线测试连灌过值的句子也回 `意图/null`」（2026-09-29），后来查明跟发布无关，是**必选参数 + 默认意图被 PUT 抹掉**这两件事（2026-09-30 02:3x 修正）。
- **训练**：`POST /api/corpus/skills/<sid>/update/model`，无进度无提示。**判训练成没成没有硬指标**（概览页那句「模型训练状态」我在界面上没找到，状态接口全 404）。唯一能用的判据是改完立刻真机喊一轮，看盒子 `/log` 有没有 POST（2026-09-29 07:1x 定）。
- **真机测试**绑定：控制台点「添加设备」→ 对音箱说「打开技能测试」→ 它念 6 位语音验证码 → 回填。我全自动化跑通过（`say -v Tingting` + whisper 取码 + 原生 setter 填框，2026-09-29 08:43，`POST /api/skill/<sid>/bind` 200）。**一台音箱同一时刻只在一个技能的测试态里** —— 并行开两个技能必踩（2026-09-29 09:1x 踩过一次）。
- 自用免审核：文档原文「若技能只是用来测试或个人使用，只要开启真机测试即可，不必提交审核」（2026-09-27 读到，**审核那条路我没走过，没测过**）。

### 2.4 私有技能 vs 自定义公有技能：NLU 一样，服务部署不一样

- **NLU 行为完全一样**：113665（私有/个人）和 120248（自定义公有）在同一分钟拿同一批句子打，都是"在实体里就通、不在就 `意图/null`"，**没发现私有更宽松**（2026-09-29）。别再指望"建个私有的就能收任意话"。
- **差别在「服务部署」保存这一步**：个人技能（2026093038210 / 内部 id 120282）点「下载认证文件」回 `retCode:2002 没有访问资源的数据权限`，前端拼出的 URL 是 `token=undefined`，`PUT /api/hybird/logicConfig` 一律 403 → **UI 上这条路是死的**（2026-09-30 00:3x）。
- 但**意图级 PUT 能绕过**：`PUT /api/skills/<sid>/intents/<iid>` 把 `webhook.url` 直接塞进去，运行时平台真的拨（120282 的 webhook 就是这么活的，2026-09-30 02:3x~06:0x 网页在线测试两次真 POST 打进盒子）。**注意：120282 至今的证据全部来自网页在线测试，不是真机** —— 真机整链证据在 120248 上。
- 顺带一条会省你力气的：免调用词的「无调用词应用」创建权限保留给**合作厂商**，个人号只能建有调用词的技能；且文档写明「关联账号的真机测试，无法测试无调用词应用」（2026-09-27 读到的原文，**没测过** —— 我连入口都点不到）。

### 2.5 服务部署的认证文件校验（这是第一道门）

保存 URL 时阿里后端真的会发一次 `GET <我的域名>/aligenie/<md5(技能id)>.txt`，比对内容才放行；HTTPS 还要求证书有效。

- 文件名 = **`md5(技能id)`**，内容 = 一份账号 token 拼接（前 42 字符全账号相同、后 22 位每技能不同，**推不出来，只能从「下载认证文件」按钮拿**，2026-09-28~30 实测）。
- 我的服务端只在 GET 到 `.txt` 时原样吐出并写一行日志（`genie/genied.py:370-382`）。**判"平台来没来过"必须看这行新日志**，因为 `genied` 只在未匹配时才 log（2026-09-30 00:3x 踩过）。
- 坑：**认证文件抓不到 → 所有 PUT 都回 403 `retCode:3010 未正确获取到认证文件`**，这跟 CSRF 无关，别去查 cookie（2026-09-30，换域名之后必踩一次）。
- 可选 RSA 鉴权，**公钥必须 1024 位**（文档口径，2026-09-27，**没测过**）。

## 3. 能力边界：**能不能不枚举**（最关键的一节）

### 3.1 结论先摆出来

**第一轮不可能不枚举。** 实体值必须预先灌进平台，不在清单里的说法在阿里的 NLU 就被丢掉，我们的服务端一条 POST 都收不到。自由词不是"解析得不好"，是**根本不出现在请求体里**。

这条是被三种形态各否证一次的，不是从文档推的：

| 试的路 | 怎么试的 | 结果 | 日期 |
| --- | --- | --- | --- |
| 默认意图 + 整句 | 0 语料 / 0 参数 / 没训练的空白技能 120266 | 「松鼠同学，影子为什么会跟着我」→ POST 里 `utterance` **只剩 `"松鼠同学"`**（我逐字录过自己说的原话） | 2026-09-29 08:44~08:47 真机 |
| 我们自己的 `ASK_INF` 开麦续第二轮 | 同上，回「您说。」→ 它确实开麦 → 说「太阳为什么那么大」 | **零 POST**，音箱自己念了一大段天体科普 —— 那是**平台内置百科**在答，不是我们的后端 | 2026-09-29 08:4x 真机 |
| 平台原生追问（必选参数） | 120248，`问题` 是 required | 第二轮能回来，但**按实体值匹配**，没灌过的句子回「没听清主人的话」 | 2026-09-29 全天 |
| A/B 同意图同分钟对照 | 尾句在实体里 vs 不在（「为什么天空是蓝色的」「噼里啪啦轰」） | 在 → 通；不在 → `UNKNOWN_DOMAIN`、零 POST。**默认意图补回来 + 必填关掉，都救不了** | 2026-09-30 02:3x |

**能不能续到第二轮，取决于这个意图有没有"待填的必选参数"，不取决于 `ASK_INF`** —— 这句是 2026-09-29 08:4x 那轮拿 120266（0 参数）和 120248（必选参数）对照出来的，值得贴在屏幕上。

所以：**能进后端的自由文本只有 `必选参数 + 平台原生追问 + 实体值清单` 这一条，本质仍是枚举。**

### 3.2 「调用词 + 任意一句话」这条我为什么彻底放弃

见上表第一行。尾巴不是我们截的，是平台在 NLU 阶段切的 —— 我们的服务端只看见调用词四个字。这条一旦被说服，所有"正则兜底 / 规则引擎 / 后端再判一次"的主意都是空转（我 09-29 早上真的提过，被这条实测堵回去了）。

也别指望"句子中含一个灌过的词就能命中"：`我特别想放动画片`（`放动画片` 就是实体值之一）**零 POST**，必须**整段对上**（2026-09-29 真机）。

### 3.5 还有一堵墙：ASR 的同音字，平台不做模糊

这条会让人误判"链路坏了"，所以放在能力边界里。

- **整句匹配错一个字就 0 POST**（2026-09-29 全天反复验证）。
- 我拿脚本量化过一次：每条候选用 `say` 慢速合成、喂 whisper 转写、逐字比原文 —— 20 条菜名里**只有 6 条说得清**（青蛙、鹦鹉、长颈鹿、冷笑话、四面楚歌、脑筋急转弯）；企鹅→起鹅、北极熊→被指雄、恐龙→洪农、嫦娥奔月、卧薪尝胆、葫芦娃全在"听歪"那一栏（2026-09-30 00:1x）。
- 真人喊也会歪：「打篮球怎么防守」在 4 种语速下都被听成「**大**篮球怎么防守」（2026-09-30 批量抽测）；「桃树→陶樹」「水獭→水塔」同理。
- **所以：候选/说法要写短（「企鹅」两个字比「讲讲企鹅」命中率高）**，同音字多的词天生低命中，换语速换间隔救不回来。

### 3.6 「某个词不进后端」不一定是 NLU 丢的，可能被官方抢了

两条硬证据：

- `能不能放动画片` 同一句，23:52 / 23:53 进我们的意图，23:54 / 23:58 被平台自己的视频领域接走（音箱念「请打开电视屏幕观看相应的视频」，我们零 POST）（2026-09-29）。

## 4. 唯一的活路：`resultType:"SELECT"`，服务端当场报菜名

**它绕的是第二轮。** 官方《语音响应协议说明》(`ehac4c`) / 2.0(`megzio`) / 《动态意图》(`omuzxq`) 里这条的语义是：响应里带回候选词列表，平台念完回复**自己开麦**，下一句话拿去跟**服务端当场给的候选**配对，命中后照常 POST 回来。

**这些候选从没进过控制台、没点训练、没发布** —— 这是整份调研里唯一一条"不提前导入"的正解。

### 4.1 响应形状（线上代码就是这份）

`genie/genied.py:112-132`：

```json
{"returnCode":"0","returnMessage":"","returnValue":{
  "reply":"有这些：企鹅、青蛙、乌龟、袋鼠、蝴蝶、北极熊、长颈鹿、一箭双雕，要哪个？",
  "resultType":"SELECT",
  "askedInfos":[{"parameterName":"问题","intentId":199538}],
  "selectParaInfo":{"intentParameterName":"问题",
    "candidateList":[{"value":"企鹅"}, …],
    "parameterReplyMatch":true,"selectIndexMatch":true}}}
```

- `parameterReplyMatch:true` = 候选之外**也认实体里灌过的值**；`selectIndexMatch:true` = 「第 N 个」不至于跳出去（这两个字段名对不上的地方见 4.3）。
- `askedInfos` 里的 `intentId` 直接从请求体顶层取，不用硬编码（2026-09-29 实测真机 POST 顶层就带）。

### 4.3 三条必须知道的细节

1. **下标 0-based**（2026-09-30 08:0x 真机：「第二个」=`[1]`、「第十二个」=`[11]`）。
2. **说「第 N 个」时槽位值是空串**，平台只给下标 —— 所以必须自己记住刚发出去的那份候选。线上做法：回 SELECT 时按 `sessionId` 存进 `SENT_MENU`（只留 50 个会话），第二轮 `menu_pick()` 取第 n 条**原文**覆盖 `utterance` 和槽值（`genied.py:52`、`genied.py:141-152`）。**为什么要绕这一圈**：ASR 听歪（北及星）时平台仍可能按 `parameterReplyMatch` 对上候选，但拿听歪的字去查答案库会落空 —— 用下标拿回原词，秒答必中（2026-09-30 00:1x 假报文验证：喂「青花」+ `[0]` → 日志 `下标对上：「青花」→「青蛙」`）。
3. **序号这条自己打过一架**，诚实记一下：2026-09-29 上午 + 12:0x 两次真机「第二个」→ 零 POST，回的是平台全局「第 N 个 / 闹钟」和「抱歉您尚未绑定天猫魔盒」；2026-09-30 06:0x 网页测「第三个」→ `UNKNOWN_DOMAIN`；但 2026-09-30 08:0x 真机「第二个」拿到了 `[1]`。**我倾向于差异在"是否在菜单念完之后、且会话还在这个技能里"，但这只是解释，没做对照实验**。别把它当稳定能力用，点菜优先念菜名本身。

### 4.4 候选从哪来：只能来自本地文件

**候选必须在那 1.5 秒里出得来**（第 5 节），所以不能现场问大模型（5~20 秒）。线上做法：候选 = 盒子 `/var/lib/genie42/片单.txt`，一行一条，`open()` 现读、改完不用重启（`genied.py:103-109`，实测 0.00~0.02 秒出 SELECT，2026-09-29 13:1x 连续五次）。**正确用法就是官方举的那个例子**：先把片单/热榜备在本地文件里，回 SELECT 时报菜名，他念哪条干哪条。

### 4.5 菜单条数 ↔ 第二轮窗口（这是实际最好用的旋钮）

- `MENU_MAX = 10`（`genied.py:51`）—— **这个 10 是我自己代码卡的，不是平台卡的**：片单写 14 条时只发出去 10 条；写 20 条时（临时调高）平台全收全念（2026-09-29 12:1x、09-30 08:0x）。
- 念完耗时：3 条 ≈ 6 秒（2026-09-29 13:1x、21:1x 两次）；10 条 ≈ 13.5 秒（2026-09-30 08:0x）。**另有 20 秒 / 36 秒 / 40 秒+ 三个记录**（09-29 13:1x / 09-29 10:1x / 09-30 04:00），语速和标点不同，**我只敢用「一条 ≈1.3 秒 + 留 2 秒」这个估算，没做过严格计时**。
- 裸调用词**自己也会触发一次菜单**（会话还在时），于是连念两遍 ≈ 26 秒，第二轮直接掉在菜单中间（2026-09-29 22:0x）。这个坑后来是靠"裸调用词不报菜名、只回『您说。』"绕开的（2026-09-30 07:5x 改回，`genied.py:297-301`）。
- 菜单触发词只认**整句精确匹配**（剥掉调用词和句尾「吗呢啊吧」再一比一），10 条词表见 `genied.py:49-50`；「有哪些」「有什么好看的」这类**故意不当触发词** —— 它们是正常提问的尾巴，而且会被官方抢（`genied.py:48` 注释、2026-09-30 05:0x / 07:0x 两轮教训）。
- 只对白名单意图放行（`MENU_INTENTS = {199486, 199538}`，`genied.py:47`）：**按意图名放行会波及别的技能**，09-29 那次我的菜单接管了并行会话的技能，日志里 `intent=nlunlu → menu(5)(SELECT)` 就是事故现场。

## 5. webhook 的硬约束：**平台肯等你几秒**

### 5.1 响应必被 TTS 念，而且只能念

- `returnValue.reply` **一定会被音箱念出来，没有"只返回不吭声"这种选项**（官方《语音响应协议》原文「平台会将文字合成语音播放」，2026-09-27 读；每次真机都验证了这条 —— 音箱念的就是我塞进 `reply` 的字符串，2026-09-29/30 全天）。
- **不能返回 HTML**：`genied.py:357-368` 里除了认证文件（`text/plain`）和状态页（`text/html`），POST 一律 `application/json; charset=utf-8`。
- **Content-Type 不能是 `text`** —— 文档原话「响应头信息是 content-type: text，会导致平台抛出 JSON 反序列化异常」（2026-09-27 读到）。**注意这条我只在文档里读到，没有专门构造一次 text 响应去复现 —— 没实测过**，但我按它写了。
- `actions` 只认 `audioPlayGenieSource`（素材库音频 ID，给不了外链 URL）和 `playTts`；`gwCommands` 一旦使用，原 `reply` 字段**被忽略**、开麦改用 `Speak` 指令的 `payload.expectSpeech`（文档口径，2026-09-27，**两条都没测过**，我的代码只用 1.0 的 `returnCode/returnValue` 形状）。

### 5.2 1.5~2 秒这个数是怎么量出来的

**官方 112 页文档里一个时延数字都没有**（2026-09-27 通读确认）。所以我自己二分：

- 做法：服务端只对**一句指定的句子**在返回前硬 `sleep`（`SLOW` 那个 dict，其它句子不受影响），我对着方糖念这句，只回「播 / 不播」，用时从 `genied` 的 `/log` 里读。
- 结果：**1s 播 → 1.5s 播 → 2s 不播 → 3s 不播**（2026-09-29 注入延迟二分）。
- 所以「平台等这一跳的预算在 1.5~2.0 秒之间」。线上按最保守的取：`FAST_BUDGET = 1.5`（`genied.py:28-29`），超过就在日志里打警告（`genied.py:327-328`）。

**这个数有几条边我没量，你要知道**：

1. 这是**服务端自己计的**耗时，**平台那头还要加 HTTPS 握手 + cpolar 一跳**，真实预算比 1.5 秒更紧 —— 加了多少**没量过**。
2. 4 个刻度每个只测了 1 次，**没做重复**；跳变点到底在 1.5 还是 1.8，**没细分**。
3. **平台超时之后会不会重试**：没测过。（另有一个独立观察：一轮呼叫平台会连发两次 POST，间隔 1~2 秒、`utterance` 相同 —— **这是观察不是结论**，我没敢当重试，也没做去重，2026-09-29 07:1x。）
4. `ASK_INF` / `CONFIRM` / `SELECT` 用的是不是同一条预算：**没测过**（我只在这些形状上跑出 0.0x 秒，从没故意慢给过）。
5. 慢答案后台跑完时平台会话还在不在：**已经不指望了**。豆包 5~20 秒 >> 2 秒，所以设计上就是"这一跳先垫一句『我查一下啊。』，答案从电视出声"（`genied.py:309-315`，2026-09-30 真机：垫词后 1 分 54 秒电视才响）。

### 5.3 `sessionAttrs` 不开放

官方明确写了「`sessionAttrs`（往下一轮带临时 K:V）**目前不对 webhook 服务开放**」（2026-09-27 读文档确认）。**跨轮状态只能自己按 `sessionId` 存** —— 线上那份 `SENT_MENU` 就是这个的替代品（`genied.py:52`）。这条不用实测，官方不给就是不给。

### 5.4 上下文默认保留 → 第二轮**不用带调用词**（这条很值钱）

- 文档 §2.2「对话结束响应__清除对话上下文」：普通结束响应**依然留在这个技能的对话上下文里**，「在技能的上下文中，可以只说意图的语料进入意图，而不需要再加上调用词」。要清上下文必须显式回 `skillDialogSession.skillEndNluSession=true`（默认 false）。
- **我从来没设过这个字段，所以默认就是保留 —— 别画蛇添足去加。**（2026-09-27 读文档 + 全程代码核对）
- 真机报文佐证（2026-09-30 07:2x）：连着问的几轮里 `skillSessionId` 从头到尾同一个、`newSession:false`。**第一句带了调用词进了我们这个技能，之后每句都原封不动派给我们**，我们再回一句带开麦的（`ASK_INF` 或菜单 SELECT），麦一直悬着。
- 麦窗实测：答完之后 **10~20 秒内**可以直接问下一句（2026-09-29 06:1x 一轮一轮喊出来的），超 20 秒关；SELECT 那条的窗口另测出 **9 秒**（2026-09-29 21:1x）。放片子那条故意**不留麦** —— 否则电视的声音会被它当成你问的话（`genied.py:306-308` 就是这个决定的注释）。

### 5.5 开麦权限：不用申请

文档说要「能力申请 → 授权配置 → 勾『允许通过 Webhook 触发音箱开麦行为』」（2026-09-27 读到）。**实测：`语音交互基础权限`（含开麦）个人技能默认就是「已生效」，不用申请**（2026-09-28 在 113665 上看到的；要申请的只有 `消息推送_定制机版`）。真机 `ASK_INF` / `SELECT` 都成功开过麦，所以文档那句申请步骤对个人号是多余的。

### 5.6 参数缺失时：精灵追问那段时间完全不请求后端

- 三条正路：① 参数配默认值；② 配「精灵追问」—— **平台自己问，期间完全不 POST**，问到值才发过来（所以我们后端一定能拿到该参数）（文档口径，2026-09-27 读；真机对照 2026-09-29：先「花生同学」→ 它问「您说。」→ 再说一句不在实体里的，**追问轮同样零 POST**，音箱回「好，谢谢你」）；③ 自己回参数追问（2.0 的 `Dialog.ElicitSlot`）。
- 实测坑：**必选参数（`required=true`）会让整个意图不通**；隔壁把参数改成不必填之后同一条链立刻通了（2026-09-30 02:3x）。而"第二轮能不能回来"又依赖有没有待填必选参数（3.1）—— **这两条合起来读：默认意图 + 参数不必填 + 我们自己开麦，是唯一活着的组合。**
- 平台会把槽值念短：说 `怎么做手工贺卡` 回的是槽 `怎么做手工`（2026-09-30 下午）。**所以 ask 腿要用 `utterance` 原话问，别只信槽位**（`plan.py:174-177`）。

## 6. 公网入口：**为什么必须是 `.r6.cpolar.top`**

webhook 必须公网可达（+ 认证文件，见 2.5），我没有公网服务器，用的是 cpolar 隧道。

### 6.1 后缀不是装饰

同一台机器（`192.168.5.42`）同一账号实测（2026-09-28）：

| `-region` | 拿到的域名 | 天猫精灵表现 |
| --- | --- | --- |
| 不带 | 随机，这次是 `*.vip.cpolar.cn` | 控制台**保存时的域名校验能打到我们**、界面绿勾 ✓；但**技能运行时的 webhook 分发器永远不连** —— 在线测试和真机都回「服务开小差，请稍后重试吧」，盒子 cpolar 日志和后端日志**一条请求都没有** |
| `cn_top` | `*.r6.cpolar.top` | **换过去的下一秒**在线测试就通，真机 POST 带 `botId":10` 落进来 |
| `cn` | `*.r9.cpolar.cn` | （顺手记的对照，没细测） |
| `top` | 什么都不给，隧道起不来 | — |

**最坑的是"能自查的证据"全绿**：域名校验过、配置保存过、`webHookInfo.url` 已是新域名、Mac 上 curl 0.3 秒 200、TLS 链完整 SAN 正确 —— 只有「平台到底连没连」这一条要靠**数隧道日志里的连接数**：`grep -E "pxy:pxy.*New connection|prv:prv.*New connection" /var/log/cpolar/genie.log`，**零连接 = 边缘节点/URL 问题，不是我们后端慢**（2026-09-28 花了一小时才定下来；`-region=cn_top` 从此绝不能删）。

### 6.2 free 套餐随机域名的三个后果

1. **每次重启/重连必换域名**，换了要回控制台改服务器 URL。**`cpolar-genie42` 这个服务不能随便 restart**（`genied42` 可以）。
2. **域名甚至会在不换进程的情况下自己变**：`NRestarts=0`，但日志里 21:59 已经重新拨成新域名（2026-09-30 06:0x 抓到）。现抓现用：`grep "Tunnel established" /var/log/cpolar/genie.log | tail`。
3. **更狠的：free 域名会被回收给别的租户。** 控制台里存的还是那个域名、盒子侧隧道也自称是这个，但公网 curl 回去是**别人家的页面**，后端零 POST，真机整批零 POST（2026-09-30 13:0x 撞过一次）。**所以每轮开测前必须 `curl http://<控制台里那个域名>/status`，认出是不是我们那个 `{"ok":true,"port":8092}`** —— 只看"隧道 active"不算证据。

### 6.3 换域名之后的最小动作（09-30 实测通，不用点 UI）

`PUT /api/skills/<sid>/intents/<iid>`：body = `GET /api/skill/<sid>/intent/<iid>` 的整个 `retValue`，只改 `webhook.url`，**并且必须带上 `defaultIntent:true`、删掉 `executeLogic`** —— 光把 GET 的东西原样 PUT 回去 = 把「默认意图」抹成非默认，整条真机链立刻全哑（这个坑 2026-09-29 06:14 踩过一次：只改两条模板文字 PUT 回去 → 回读 `type` 从 `{"name":"DEFAULT"}` 变成 `null` → 06:15 / 06:19 / 06:41 三轮真机**连裸调用词都零 POST**，而同一条链 05:41~06:12 是连通的；`type` 这个字段在 PUT 里写不回去，它不是数据字段是表单上的开关）。头 `x-csrf-token: <cookie 里的 ctoken>`。改之前先确认认证文件在新域名上抓得到，否则 403 `retCode:3010`（2.5）。

**另外一条判"谁在拨"的**：公网入口要从盒子上验，别从 Mac 验 —— Mac 上 `curl https://<域名>/health` 会返回空 body（本地代理在拦），看着像服务挂了（2026-09-29）。

## 7. 文档从哪来：**语雀接口免登录抓**

`aligenie.com/doc/<bookId>/<slug>` 的正文是前端异步渲染的，WebFetch 拿不到（2026-09-27 试过）；老站点还会跳 `login.taobao.com`，加 `?tbpm=3` 能免登录读到正文，但仍然是壳。

**真正能用的是语雀公开接口，免登录：**

```
https://www.yuque.com/api/docs/<slug>?book_id=20255408
```

返回 JSON，正文在 `data.content`（lake/HTML，自己去了标签）；`data.description` 是首段摘要，很多时候看一眼就够；`body` / `body_asl` 是空的，别用。

要全量目录：`https://www.yuque.com/api/docs?book_id=20255408&limit=200` —— 一次 200 条 `{slug,title}`，比在文档站翻目录快得多（`/api/books/<id>/toc`、`/api/catalog/<id>` 都是 404，别试）。book `20255408` = 技能应用平台。

我反复回读的几个 slug：配置语料 `amm8fg`、创建实体 `qyq166`、添加参数 `sgmvp9`、动态意图 `omuzxq`、语音响应协议 1.0 `ehac4c` / 2.0 `megzio`、多轮对话 2.0 `lmepat`、NLU 结果传递 `oqkayqbgqthytltl`、意图&参数 NLU 透传 `ta84rt`。

**文档里没有的东西（别去找）**：webhook 超时秒数（0 个数字）、意图/语料/实体总数上限（0 个数字）、任何教育/视频类官方示例语料（2026-09-27 通读结论）。这三件只能自己做实验 —— 第 5.2 节和第 4 节就是给它们补的数字。

## 8. 给你的两条路

### 8.1 只要问答、不要播放 → 最省事的路线

按这个顺序做，每步都有硬判据，别跳：

1. **建一个「自定义」语音技能**（公有/私有在 NLU 上没差别，但**私有/个人技能在「服务部署」页拿不到认证文件**，所以想正经配 webhook 就建自定义，见 2.4/2.5）。
2. **调用词**：和「天猫精灵」**一个字都不要共享**（`天天同学` 共享 `天` → 5 轮全哑；换成不含 `天/精灵` 的词一次就通，2026-09-29 05:29 对照 + 05:41 正例）。**一个词同一时刻只属于一个技能**。改名不用训练，**约 4 分钟生效**（05:33 存 → 05:41 真机通）。改名后记得同步你后端那份"裸调用词表"（本仓库 `genielib/plan.py:46 SKILL_WORDS`），否则裸喊会把上一条答案再念一遍。
3. **一个意图就够**：一个必选参数 → 后来**改成不必选**（5.6）+ **设为默认意图** + **设为动态意图**。语料全用**整句例句（SAMPLE）**，别用 `@{}` 模板（那个下拉刷新就退回「例句」，且例句模式下 `@{}` 被静默拒绝）；槽位由你自己从 `utterance` 里抠（`plan.py:90-95 _tidy()`）。
4. **公网入口**：`-region=cn_top` 拿 `*.r6.cpolar.top`（6.1），放过 `aligenie/<md5(技能id)>.txt`（2.5），每轮开工先 `curl <域名>/status` 认出是自己（6.2）。
5. **一句一句灌实体值，每次点完训练就真机喊一句验**，不要"等 30 分钟"（判据只有一个：后端 `/log` 出现那条 POST，2026-09-29 07:1x 定）。**整份实体被重写/删除后不训练就会全哑**（2026-09-29 夜）。
6. **回答只回一句 `reply`，预算当 1.5 秒**（5.2）：慢的东西先垫一句「我查一下啊。」后台跑，别在这一跳等大模型（5.2 第 5 条）。
7. **第二轮一律走 SELECT**（第 4 节），别指望 `ASK_INF` 兜住任意话（3.1 第二行 —— 没待填必选参数时第二轮直接掉回平台全局 NLU）。

这条路上你唯一要花的是**灌词的时间**，不是找后门的力气。

### 8.2 你要的是**任意自由词** → 请放弃天猫精灵，改走本地拾音

**原因就三条，全在第 3 节里**：

- 自由词**在阿里的 NLU 就被丢了**，你的服务端连一个字节都收不到（3.1，四条否证）；
- 「调用词 + 任意一句话」的**尾巴是平台在 POST 里切的**，不是音箱麦克风切的（3.2，2026-09-29 08:44 逐字对照过原话）；
- 想覆盖更多话，只能往那 **10000 格**里换句子（2.2，2026-09-30 顶死过），而「动态获取实体值」那条官方接口**已暂停接入**（2026-09-29）。

**本仓库那条本地链就是给自由词准备的**：`genie/listen.py`（Mac 侧常驻耳朵：能量断句 → whisper.cpp 转写 → POST 盒子 `/local`）+ `genied.py:332-351 local()`。**耳朵听到的是完整整句**，因为切尾巴那件事只有阿里会干，whisper 不切（`genie/listen.py:29-34` 是 VAD 参数）。实测（2026-09-29 09:0x 起）：`小松鼠，影子为什么会跟着我` → 1 秒内念「我查一下啊。」→ 48 秒后电视念出答案；`小松鼠，我想看魔道祖师的动画` → 电视放魔道祖师。唤醒词故意用「小松鼠」这种**不和平台词撞**的本地词，两条链各管各的不抢答。

代价也直说：本地 ASR 有自己的同音字代价（那句「影子」被听成「银子」，答成了招财）；`subprocess.run(text=True)` 撞 whisper 的非 UTF-8 stderr 会把转写线程整个打死、聋一天半才发现；macOS 上 `urllib` 会读系统代理，到局域网必须 `ProxyHandler({})` 建 opener（`curl` 不读系统代理所以手测是通的）。这些都在 2026-09-29 踩过。

**为什么这条非写不可**：`04`/`05` 两篇讲的是本地拾音链路和它的工程细节；可行性层面你只要知道一件事 —— **要自由词就别让阿里替你听**。

### 附二：我自己记录里互相打脸的四处（照抄，别照着做规划）

写这篇时把原始流水（`docs/_原始开发流水账.md`）重新对了一遍，有四处我当时下的结论彼此矛盾，**我没能拆开验证**，列在这里而不是藏起来：

1. **「个人技能永远配不上认证文件」和「同一技能当晚收到真 POST」只隔 6 小时，中间那一步没记录。** 09-30 00:36 写死 `downloadCertificate` 回 2002、`PUT logicConfig` 一律 403、校验永远过不了；09-30 02:3x 就有真机 POST 落进盒子。我把它归因成「改用自定义公有技能 120248」，但**没有证据说明 120282 那台最终到底校没校验**。如果你只有个人技能，先别照 2.5 节放弃，自己确认一遍。
2. **同一个调用词在同一晚被判死两次、判活一次。** 09-30 02:3x 判「`小狗同学` 被官方节目抢走」，09-30 07:2x 同一技能真机路由成功。中间只改了槽位必填和默认意图 —— 「官方抢答」这一层为什么消失我没有解释，最可疑的是当时方糖处在另一个技能的测试态，**但这是猜测不是实测**。
3. **「训练生效」从头到尾没有可观测终点，多处归因可能是错的。** 状态查询接口全 404，`POST /intents/update/model` 回 200 只代表请求发出去了。09-29 16:35 点训练 → 22:49 真机通，被记成「灌库＋训练生效」；可同一条链 20:18 在**什么都没改**的情况下自己通过一次。也就是说「训练落没落地」和「平台那堵不拨隧道的软墙自己回没回来」这两个变量我始终没分开测。**不要把「训练完了」当成一个可依赖的状态**。
4. **那个 10000 上限的适用范围只在一处顶到过。** 是在实体 101879（技能 120282）上撞到的；09-29 往 101852 只灌到 9828 就停了。所以「每实体 / 每技能 / 每账号」到底哪个口径、101852 能不能也上 10000，**都是推断**。要按 1 万条做容量规划，先自己验一次。

另外一处**语义差别**放在这里最容易翻车，详细写在各口对照表里（见 `docs/04-测试链路.md`）：`POST /test`（本地直打 genied，不带 `intentId`，绕开 NLU）、`POST /local`（本地拾音链的落点）、控制台 `/api/tools/test`（在线测试）、真机 —— 这四种是**四个不同的东西**，前三个通了都不代表第四个通。我至少三次拿错口得出过相反结论。
